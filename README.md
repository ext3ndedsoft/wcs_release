## 💡 О проекте

**Windows Config Studio (WCS Pro)** — это высокопроизводительный инструмент системной оптимизации нового поколения. В отличие от тяжеловесных утилит на .NET/Electron или небезопасных `.bat`-твикеров из интернета, WCS построен на монолитной архитектуре **C++20** и легковесном рантайме **Microsoft WebView2 Evergreen**.

Программа создана специально для соревновательных игроков (**Counter-Strike 2, VALORANT, Apex Legends, Dota 2, Call of Duty, Overwatch 2, PUBG, Fortnite**), которым важен каждый миллисекунд инпут-лага, идеальная плавность мыши 1:1, стабильный фреймтайм (0.1% и 1% Low FPS) и абсолютная чистота Windows без фоновых служб и телеметрии.

## ⚡ Модули и ключевые возможности

### 1. ⏱️ Низкоуровневая задержка и системные таймеры (Latency & Timers)
* **Аппаратный таймер 0.500 ms (`NtSetTimerResolution`)**:
  * Замена стандартного интервала прерываний Windows (15.625 мс) на предельный предел ядра **0.500 мс**.
  * Многократное снижение аппаратной задержки опроса мыши (1000/4000/8000 Hz) и клика.
* **Отключение Dynamic Tick (`bcdedit /set disabledynamictick yes`)**:
  * Устраняет скачки частоты системного таймера процессора при переходах между состояниями энергосбережения C-states.
* **Отключение синтетического таймера HPET (`bcdedit /set useplatformclock no`)**:
  * Перевод системного замера времени на прямой процессорный регистр TSC, исключая лаг медленного таймера материнской платы.
* **Схема «Максимальная производительность» (Ultimate Performance)**:
  * Активация скрытого профиля электропитания Microsoft (`e9a42b02-d5df-448d-aa00-03f14749eb61`).
* **Разблокировка ядер процессора (Core Unparking 100%)**:
  * Запрет на усыпление логических ядер Windows (`CPMINCORES 100`), устранение микрофризов при резкой нагрузке.

---

### 2. ⚡ Интерактивный менеджер прерываний (MSI & IRQ Priority)
* **Нативная SetupAPI интеграция**:
  * Прямой опрос Диспетчера устройств Windows в реальном времени. Фильтрует отключенные, виртуальные и фантомные девайсы, отображая только реально активное физическое оборудование.
* **Режим векторных прерываний MSI (Message Signaled Interrupts)**:
  * Перевод **GPU**, **сетевой карты**, **USB xHCI контроллера** и **аудиочипа** с устаревшего разделяемого режима Line-based IRQ на прямые векторные прерывания.
* **Приоритеты прерываний устройств (Affinity DevicePriority)**:
  * Выставление высокого приоритета обработки прерываний шины PCI для видеокарты и сетевого адаптера.
* **Киберспортивный профиль в 1 клик**:
  * Автоматическая безопасная расстановка приоритетов для минимизации DPC Latency.

---

### 3. 🎮 Dynamic Game Boost (Автоопределение игр в реальном времени)
* Фоновый сторожевой поток с околонулевым потреблением CPU (0.0%).
* Мгновенное автоопределение запуска соревновательных дисциплин:
  * *CS2, CS:GO, VALORANT, Dota 2, Apex Legends, Fortnite, PUBG, Call of Duty, Overwatch 2, Rainbow Six Siege*.
* **Автоматические действия при старте матча**:
  * Установка высокого приоритета процесса CPU (`HIGH_PRIORITY_CLASS`).
  * Сброс Standby кэша оперативной памяти для исключения просадок FPS в начале игры.
  * Фиксация интервала таймера 0.500 ms.
  * Поддержка добавления любых пользовательских `.exe` файлов игр.

### 4. 🛡️ Хирургическая оптимизация Windows 11 (23H2 / 24H2)
* Безопасные групповые политики (GPO Registry), не повреждающие целостность системных файлов:
  * **Windows Copilot**: отключение фоновых AI-процессов.
  * **Windows Recall (24H2)**: блокировка создания снимков экрана и анализа активности.
  * **Веб-поиск Bing**: исключение интернет-запросов и задержек при поиске в меню «Пуск».
  * **Реклама и рекомендации**: отключение спонсорских предложений и трекинга в «Пуске».
  * **Панель виджетов**: выключение процесса `Widgets.exe` и новостной ленты.
  * **Спонсорский блоатваре**: запрет фоновой автоматической докачки сторонних приложений Microsoft Store.
  * **Телеметрия клавиатуры**: отключение сбора паттернов ввода и рукописного текста.

### 5. 🧹 Ультра-быстрая выборочная очистка (Ultra-Fast Junk Cleaner)
* 12 независимых категорий системного мусора:
  * Временные файлы (`%TEMP%`, `Windows\Temp`, Prefetch), кэш эскизов Проводника, кэш Центра обновлений `SoftwareDistribution`, журналы событий Event Logs, кэши браузеров, кэш Microsoft Defender, дампы отчетов об ошибках WER, кэш инсталлятора Office.
* **GPU Shader Cache Cleaner**:
  * Очистка кэша шейдеров DirectX (D3DSCache / DXCache), Vulkan, NVIDIA GLCache и AMD ComputeCache при возникновении статтеров после обновлений видеодрайвера.
* **Junction & Symlink Safety**:
  * Интеллектуальный пропуск точек повторной обработки NTFS (Junction points). Очистка выполняется за **1.0 – 1.5 секунды** без зависаний.

* Полный аудит автозапуска:

* Совместимость с реестром `StartupApproved` Windows Task Manager:
  * Возможность безопасного включения и отключения приложений без удаления пути к файлу.
  * Функция полного удаления мусорных и устаревших «хвостов» автозапуска.

### 8. 🧠 Выделенный виджет Memory Cleaner
* Компактное окно системного мониторинга (390×510 px) с поддержкой системного трея:
  * Наглядная шкала распределения физической RAM (In-Use, Standby List, Free, Modified).
  * Ручной сброс рабочих наборов процессов (EmptyWorkingSet) и очистка системного Standby кэша.
  * **Автоматическая оптимизация**:
    * По настраиваемому порогу заполнения памяти (например, при достижении 80% RAM).
    * По настраиваемому интервалу таймера (от 3 до 120 минут).
    * Автозапуск вместе с Windows в свернутом виде.

## 🚀 Установка и запуск

1. Перейдите в раздел **[Releases](https://github.com/ecst4ssy/WindowsConfigStudio/releases)**.
2. Скачайте последнюю версию исполняемого файла `WindowsConfigStudio.exe`.
3. Запустите файл от имени **Администратора** (программе требуются привилегии для настройки BCD, служб и прерываний устройств).
4. *(Рекомендуется)* Создайте точку восстановления Windows на вкладке «Безопасность» перед масштабной оптимизацией.
5. Выберите желаемый профиль или настройте параметры точечно под свою систему.
