Задержка системы и процессор

Снижение задержки ввода мыши и стабилизация тактовой частоты ядер

High-Precision Windows Timer Resolution
По умолчанию Windows опрашивает события таймера раз в 15.625 мс. Лок на 0.5 мс снижает задержку мыши до минимума.
Текущее системное разрешение: 1.000 ms
Отключение динамических тиков ядра (Dynamic Tick) Фиксирует системный шаг таймера Windows, предотвращая задержки при переходе процессора между энергосберегающими состояниями.
Отключение синтетического таймера HPET Переводит системное время Windows на прямое обращение к быстрым регистрам процессора (TSC), снижая задержку ядра.
Схема питания «Максимальная производительность» Активирует схему электропитания Windows без снижения частот ядер процессора и задержек пробуждения шины.
Отключение парковки ядер процессора (Core Unparking) Предотвращает уход ядер процессора в глубокий сон, устраняя задержки пробуждения потоков в напряженных игровых сценах.
Аппаратный тактовый таймер процессора (Platform Tick) Синхронизирует системный таймер ядра с аппаратным тактовым генератором материнской платы для ровного фреймтайма.
Отключение энергосбережения процессов (Power Throttling) Запрещает Windows принудительно занижать приоритет и частоты для игровых процессов и лаунчеров (EcoQoS).
Ускоренная загрузка Windows (без анимации) Отключает круговой анимационный индикатор загрузки при старте, ускоряя инициализацию видеодрайвера.
Приоритет активного окна (кванты CPU) Выделяет максимальное процессорное время переднему плану (игре) по сравнению с фоновыми задачами.
Удержание компонентов системы в ОЗУ Запрещает сброс драйверов и ядра Windows в файл подкачки, ускоряя доступ к ним из физической памяти.
Приоритет оперативной памяти для игр Ограничивает разрастание кэша файловой системы (LargeSystemCache = 0), резервируя максимум свободной оперативной памяти для игр.

Графика & Рендер

Аппаратное планирование GPU, оконная оптимизация FSO и приоритеты MMCSS

Аппаратное ускорение графики
Аппаратное планирование видеопамяти и прямые MSI-векторы прерываний для видеоядра и звукового тракта.
Аппаратное ускорение графики (HAGS) Передает диспетчеризацию видеопамяти напрямую графическому процессору для снижения задержек рендеринга.
Прямые прерывания звуковой карты (MSI Mode) Переводит аудиоконтроллер на режим Message Signaled Interrupts, устраняя треск звука и рассинхрон при высокой нагрузке.
Прямые прерывания видеокарты (MSI Mode) Переводит видеокарту на современные MSI-прерывания с высоким приоритетом, снижая задержки DPC и устраняя микрофризы.
Оконный режим и оптимизация игр
Чистый эксклюзивный доступ к дисплею без задержек композитора DWM и отключение фоновой видеозаписи.
Прямой полноэкранный режим (FSO) Отключает принудительную оконную оптимизацию Windows, возвращая чистый эксклюзивный Fullscreen.
Отключение фоновой записи GameDVR Отключает постоянную фоновую видеозапись и оверлей Xbox, освобождая ресурсы видеокарты.
Планировщик MMCSS & Мультимедиа
Выделение 100% ресурсов центрального процессора под соревновательные игры и отключение сетевого троттлинга.
Игровой приоритет мультимедиа (MMCSS) Предоставляет 100% ресурсов планировщика потоков и снимает искусственные лимиты Windows для игровых процессов.
Снятие сетевого ограничения Windows Отключает троттлинг сетевых пакетов Windows при одновременной нагрузке на процессор.

Интерактивный менеджер прерываний (MSI & IRQ Priority)

Перевод аппаратных устройств в режим Message Signaled Interrupts для снижения DPC-задержек и устранения микрофризов

Управление прерываниями PCI-устройств 0 / 0 MSI активно
Перевод устройств в режим прямых векторных прерываний MSI (Message Signaled Interrupts) снижает DPC-задержки и устраняет статтеры при опросе мыши и отрисовке кадров GPU.

Пинг & Инпут-лаг

Снижение сетевых задержек TCP, линейный отклик периферии 1:1 и отключение фоновой телеметрии

Сетевой стек и оптимизация TCP (Снижение пинга)
Мгновенная отправка пакетов без ожидания заполнения буфера (Nagle OFF), автоподстройка TCP и сброс сетевого кэша.
Мгновенная отправка пакетов (TCP NoDelay) Отключает алгоритм задержки Nagle, отправляя сетевые пакеты в онлайн-играх без ожидания буфера.
Автоподстройка окна приема TCP (Auto-Tuning) Оптимизирует размер окна TCP и распределяет сетевой трафик между ядрами процессора без очередей пакетов.
Оптимальное время жизни пакетов (TTL 64) Устанавливает эталонное значение времени жизни IP-пакетов (TTL = 64), снижая задержки маршрутизации на игровых серверах.
